# 移动端适配测试指南

## 快速测试

### 方法 1: Chrome DevTools 移动端模拟

1. 启动开发服务器：
```bash
npm run dev
```

2. 在 Chrome 中打开网站（通常是 http://localhost:5173）

3. 按 `F12` 打开开发者工具

4. 点击设备工具栏图标（或按 `Ctrl+Shift+M` / `Cmd+Shift+M`）

5. 测试以下设备：
   - **iPhone SE** (375x667) - 测试小屏幕布局
   - **iPhone 12 Pro** (390x844) - 测试标准移动端
   - **iPhone 14 Pro Max** (430x932) - 测试大屏移动端
   - **iPad Mini** (768x1024) - 测试平板布局

### 方法 2: 响应式设计模式

1. 在 Chrome DevTools 中选择 "Responsive" 模式

2. 手动调整宽度测试关键断点：
   - **760px** - 主要移动端断点
   - **375px** - 小屏幕优化断点
   - **860px** - 平板断点

## 测试检查清单

### 首页 (Homepage)

- [ ] 轮播从三列变为单列堆叠（标题 → 图片 → 元数据）
- [ ] 标题文本居中对齐
- [ ] 图片不超出屏幕宽度
- [ ] 菱形装饰框架正确显示
- [ ] 元数据文本居中且可以换行
- [ ] 页头信息从横向变为纵向堆叠
- [ ] 页脚元素居中显示
- [ ] 无横向滚动条

### 详情页 (Detail Pages)

点击任意领域卡片进入详情页：

- [ ] 返回按钮触控区域足够大
- [ ] 标题和描述文本可读
- [ ] 双栏布局变为单栏
- [ ] 图片画廊高度适中（280px @ 760px，240px @ 375px）
- [ ] 文本段落宽度舒适
- [ ] 页面可以正常滚动
- [ ] 无内容被裁剪或隐藏

### 交互测试

- [ ] 所有按钮和链接可以轻松点击（44x44px 最小触控目标）
- [ ] 轮播可以通过上下箭头键导航
- [ ] 点击图片可以进入详情页
- [ ] 返回按钮功能正常
- [ ] 页面过渡动画流畅

### 视觉测试

- [ ] 字体大小适中，易于阅读
- [ ] 间距合理，不会太拥挤
- [ ] 图片加载正确
- [ ] 颜色对比度良好
- [ ] 焦点状态清晰可见

### 性能测试

- [ ] 页面加载快速
- [ ] 滚动流畅无卡顿
- [ ] 动画过渡自然
- [ ] 图片加载不阻塞渲染

## 已知的移动端优化

### 自动应用的特性

1. **触控优化**
   - 所有按钮最小 44x44px
   - 链接有足够的触控区域

2. **滚动优化**
   - iOS 动量滚动已启用
   - 防止横向滚动

3. **安全区域**
   - 自动适配 iPhone 刘海屏
   - 内容不会被遮挡

4. **文本优化**
   - 防止横屏时字体自动调整
   - 行高优化提升可读性

5. **图片优化**
   - 硬件加速已启用
   - 自适应容器宽度

## 常见问题排查

### 如果看到横向滚动条

检查以下元素：
- 图片是否正确限制宽度
- 文本是否允许换行
- 固定宽度元素是否使用了 max-width

### 如果触控目标太小

检查元素是否：
- 有 min-width 和 min-height
- 有足够的 padding

### 如果布局没有响应

确认：
- 浏览器窗口宽度在断点范围内
- CSS 文件已正确加载
- 媒体查询语法正确

## 构建和部署

测试完成后，构建生产版本：

```bash
npm run build
```

预览生产构建：

```bash
npm run preview
```

在生产环境中，同样应该在移动设备上测试实际效果。

## 真实设备测试（推荐）

如果可能，在真实移动设备上测试：

1. 确保开发服务器可以从局域网访问
2. 在移动设备浏览器中访问 `http://[你的电脑IP]:5173`
3. 测试实际的触控体验
4. 检查在真实网络条件下的性能

## 反馈和迭代

如果发现任何问题：
1. 记录设备型号和浏览器版本
2. 截图或录屏问题
3. 描述预期行为和实际行为
4. 检查浏览器控制台是否有错误
